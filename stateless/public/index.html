3. Autorizar as contas temporariamente

Esta versão técnica usa chaves temporárias. Elas são enviadas pelo HTTPS, criptografadas como segredos do GitHub Actions e removidas após a execução, inclusive quando o job falha. O Installer não as armazena.

Pré-requisito: conectar o GitHub à Vercel, permitindo acesso ao repositório criado automaticamente. Nunca envie tokens por chat.

4. Proteção de custo zero

O sistema limita a seleção aos planos Free/Hobby; nenhum software pode prometer que o uso futuro nunca terá custo em serviços externos.

Protótipo de engenharia: é necessário validar OAuth, permissões da Vercel, provedor de banco, migrações e segurança do fluxo em homologação antes do uso público.
