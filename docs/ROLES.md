# Responsabilidades e isolamento

| Papel | Responsabilidade |
|---|---|
| Mantenedor KAIRÓS | Evoluir e documentar Core/Installer |
| Administrador da célula | Criar contas GitHub, Supabase, Vercel; aprovar termos/custos; controlar acesso |
| KAIRÓS Installer | Orientar instalação e, futuramente, provisionar somente com consentimento |
| KAIRÓS Core | Aplicativo implantado na infraestrutura própria da célula |

Este Installer não é um portal de hospedagem SaaS. Cada instalação opera isoladamente e não utiliza o banco do mantenedor.
